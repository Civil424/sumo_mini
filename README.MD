# sumo mini
Программа для моделирования и редактирования дорожной сети.
На данный момент реализовано создание дорог, узлов, перемещение и удаление.
В будущем планируется реализовать симуляцию дорожного движения.

# управление
`right shift` – режим редактирования дорог
`lmb` - создание дороги и узла
`left shif + lmb` - перемещение узлов
